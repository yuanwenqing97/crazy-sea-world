# 漂流纪元：庇护所 V4 · 地图与地貌优化版

此 ZIP 是可通过 GitHub Actions 构建的 Android 项目源码，不是已编译 APK。游戏页面离线内置在 `app/src/main/assets/www/index.html`，应用强制横屏。

## V4 本次地图改进

- **6400 × 4200 连续世界**，十个海域保持原有危险分区与目标标记。
- **不规则海岸线**：海滩、浅滩、岛内地表与外海阴影是分别绘制的 Canvas 层，不是固定地图图片。
- **地表色块与路径**：新增裁剪在海岸线内部的手绘风格地貌色块、蜿蜒土路与轻量笔触。
- **更密集的生态簇**：树木、灌木、岩石和生物群落遗迹按照海域风格生成，含固定世界坐标、碰撞判定和镜头跟随。
- **修正物件绘制层级**：修复基地绘制过程意外恢复 Canvas 世界变换的问题，避免树木、资源、宝箱、敌人与玩家在地图上消失。
- 原有的 4 名英雄、4 项可升级/变形技能、10 类海域敌人与多阶段 Boss、随机装备掉落、庇护所设施均保留。

## 构建 APK

1. 解压本项目 ZIP。
2. 在 GitHub 创建一个单独的私有仓库，例如 `drifting-era-android-v4`。
3. 用 GitHub Desktop 克隆该仓库，将本项目的所有文件复制到仓库根目录；确认隐藏的 `.github/workflows/build-apk.yml` 也复制进去。
4. 在 GitHub Desktop Commit 并 Push。
5. 打开仓库的 **Actions**，等待 `Build Drifting Era V4 APK` 成功。
6. 打开成功运行记录的摘要，找到 **Artifacts**，下载 `drifting-era-v4-apk`，解压得到 `app-debug.apk`。
7. 将 APK 传到安卓手机安装。

## 重要说明

- 本项目包是源代码，不是现成 APK；当前制作环境无法直接生成并验证最终 APK。
- 应用包名为 `com.driftingera.game.v4`，可以与此前版本并存。
- 游戏是离线单机原型；存档在应用本地 WebView 存储中。卸载应用或清除数据可能丢失存档，请先使用游戏内可用备份能力（若有）或保留旧版本数据。
- 地图美术由 Canvas 程序化绘制，已经不是固定图片；目前仍是独立开发原型，和《饥荒》正式游戏的手绘美术质量仍有明显差距。
